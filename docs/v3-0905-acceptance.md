## 完成定義

現有 v1 地端示範不能當成 v3 正式版。正式版必須有可實際操作的本機介面、真實資料或使用者匯入之可驗證資料、完整實驗與統計輸出，以及可驗證的部署原始碼。公開 GitHub 儲存庫需另經使用者授權。不得以隨機或合成行情冒充真實回測。不得把 GitHub Pages 當成可執行 Ollama 的後端。

## 對文件矛盾的明確處理

- §3.3 主文要求 compute-matched，表格仍寫 5 次。主配置將 D 的 6 次辯論與 1 次裁決都計入，B 因此為 7 次；5 次保留為另標記的比較配置，不混合統計。
- 摘要指定 Corwin–Schultz 成本，內文仍描述初期無成本。保留 `zero` 與 `corwin_schultz` 兩種成本輸出，明示設定，不把零成本結果標為成本調整結果。未取得必要 OHLC 不估造價差。
- 文字列出 AST，現有股票名單為 ASTS。先沿用 ASTS，介面與協議皆記錄實際代號；來源下載須驗證。
- B 的同一 prompt 不加入樣本編號或先前採樣輸出。種子若使用，須在模型選項而非 prompt 內變動。
- 同輪 Bull/Bear 可因地端算力順序運算，但兩者讀取的歷史必須相同，不能讓後者看到前者當輪新輸出。
