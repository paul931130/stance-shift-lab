# v3-0909.6：財務語意驗證的誤判修復

v3-0909.5 將 SEC 點時欄位的數字改寫成「營收成長」、「財務壓力」或「虧損」時會拒絕該輸出，避免 `NetIncomeLoss` 被誤解為公司虧損。實測時發現規則把新聞標題中的「AI infrastructure growth」也誤判為財務趨勢，導致 A、C、D 的模型回應可重試失敗。

v3-0909.6 將檢查縮限為明確指向營收、現金流、資產、負債、淨利或基本面的品質與趨勢敘述。市場、產業與新聞所述的需求或基礎設施成長仍可使用；若要主張公司營收或獲利的變化，仍必須有相應的比較期證據。

舊版工作與其提示詞、種子、重試規則保持不可變。請使用「複製至新版」建立新的工作，不要繼續舊版暫停工作。
