# v3-0908.2 本機回測修正版

解壓縮後開啟 Docker Desktop 與 Ollama，執行 `research.cmd setup`，再執行 `research.cmd start`，瀏覽 http://127.0.0.1:8000/ 。模型、資料來源金鑰及新聞 CSV 由使用者自行準備。

本版修改研究與決策提示詞，因此使用新的協議版本，舊實驗保留且需「複製至新版」重跑。不得把舊 AAPL/NVDA 輸出當成新版驗收結果。

- 基本面摘要只允許引用證據中存在的數值；禁止換算單位或自行四捨五入。驗證失敗會使用來源摘錄並標示 degraded，正式統計排除。
- 任一不存在的決策引用 ID 都會令該步失敗，成功步驟保留，按繼續可重試。缺資料對照仍可執行，錯誤不轉成 NoTrade。
- 情緒研究保留跨公司與市場新聞作為脈絡；提示詞要求清楚標示被提及的公司，不能把它寫成目標公司的直接事實。
- 數值驗證能抓到來源不存在的數字，不能保證相同數字一定歸屬正確指標；正式研究仍需人工抽查。

壓縮包不含金鑰、資料庫、原始新聞、模型、舊 Node 原型。首次建置需要網路下載 Python 相依與模型。只用於本機回測，不包含券商下單。
