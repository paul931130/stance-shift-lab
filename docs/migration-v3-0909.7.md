# v3-0909.7：基本面點時欄位不再作為決策特徵

SEC XBRL 的單一營收、資產、負債、現金流與 `NetIncomeLoss` 欄位仍完整保留在四域研究報告、資料快照與匯出檔。但這些點時數值沒有同口徑比較期、成長率、估值或財務品質證據，因此不能支持「強營收」、「財務壓力」或價格方向的決策論述。

新版將來源鎖定的基本面欄位從 A／B／C／D 的決策提示與可引用 ID 清單移除；決策僅使用時間序列技術指標、目標公司新聞情緒與總經資料。這不是刪除基本面資料：介面仍會呈現正確格式化的來源鎖定摘要，完整資料仍可在研究產物中稽核。

這項規則避免小型本機模型重複將稅務 taxonomy 或數字大小當成盈虧、品質或趨勢。舊版工作保持不可變，請以「複製至新版」重新執行。
