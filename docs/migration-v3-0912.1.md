# v3-0912.1：正式就緒、SEC 可比較證據與時間量測

`v3-0912.1` 修正會改變資料品質門檻、決策可見證據與執行時間量測，因此既有工作保留原協議，不能直接續跑或併入新版統計。請使用「複製至新版」建立可追溯的新工作。

## 行為變更

- 資料狀態分成四域證據完整、SEC 基本面可比較、FinBERT／新聞品質、60 日主要回測行情與 90 日次要回測行情；`formal_experiment_ready` 不再等同於只有四域資料。
- 新採集的 SEC 資料以相同 XBRL concept、相近 duration 與前一年期間建立同比數值，並可建立同 filing 的負債／資產比。原始數字以 Decimal 讀取，輸出保留來源值。
- 決策提示只接收可比較的 SEC 指標。舊版點時欄位仍保留供稽核，但需勾選資料品質敏感性覆寫才能建立新工作。
- 新聞存在時，歷史實驗預設要求目標公司提及率至少 50%，且所有標題完成固定版本 FinBERT 評分。情緒域整體缺失仍可依缺資料策略執行對照。
- 任一不存在的引用 ID 都會觸發模型重試；不再允許 80% 有效引用率放行。
- 自動行情下載的分析日前視窗由 400 個日曆日延長為 900 日，使 60-session 非重疊歷史基準有機會達到至少八窗。
- 執行時間改採服務端 monotonic clock 量測。供應商回傳的 duration 仍保留在單次 audit，但不再直接加總成組間 wall time。

## 既有資料與工作

- 既有 dataset ID、job ID、結果與匯出內容不會被改寫。
- 舊 dataset 若只有 SEC 點時欄位，可用敏感性覆寫做 demo；不得標為正式主實驗。
- 要建立正式資料，請對同一 ticker／analysis date 使用 `collect -Refresh -UseFinbert`，確認 readiness 顯示 SEC 可比較、FinBERT 完整與 60 日行情均通過。
- 舊協議的完成結果只能作歷史稽核或冒煙證據，不與 `v3-0912.1` 合併統計。
