## 研究問題

> 當看多與看空代理人由不同基礎模型擔任時，自我反駁式立場交換辯論（D）相對固定立場辯論（C）的投資決策效果是否改變？

估計量：在指定的模型組合 {A, B} 下，(D−C)_hetero 與 (D−C)_homo 的差，也就是交互作用。這個估計量同時包含模型能力組成的改變，結果只適用於這組 A、B，不能解讀為「異質性」的一般效果（Part-C 第 2 項）。

## 分析計畫（草稿）

1. **主要估計量**：Δ_interaction＝(Acc_D,hetero − Acc_C,hetero) − (Acc_D,homo − Acc_C,homo)；Sharpe 的交互差定義相同。
2. **AB／BA 的合併方式**【待鎖定】：同一案的兩種指派不能當成 360 個獨立案例，也不能把兩個 Sharpe 取平均。
3. **檢定**【待鎖定】：建議以日期區塊共同重抽樣（案例與日報酬一起抽），每次重算四個 accuracy 與 Sharpe 後取交互差，報告 95% 區間；不使用普通 McNemar。
4. **判定規則**【待鎖定】：建議比照 RQ1，accuracy 與 Sharpe 兩個交互差都要為正，而且在 Holm 校正後顯著，才判定「異質使 D 相對 C 改善」。不能用「hetero 顯著、homo 不顯著」當作證據。
5. **次要／診斷**：Bull/Bear 分歧、各模型偏多或偏空的傾向、B 的 `unsupported_numbers` 比例、重試數、tokens、延遲；裁決者採用哪一方的比例（依模型分層）。
6. **敏感性**：30、90 日；不計成本；守門員之後的決策；排除 37 個低新聞量案例；若有 B/B，報告 B/B 的 D−C。
7. **失敗處理**【待鎖定】：在看到結果之前先訂好。建議：某案任一組失敗 → 該案所有組一起停止並可續跑；權重 digest 改變 → 整案作廢。不得依模型失敗率另外挑選配對集合。

## 已知限制（執行前）

- A/A 換成 A/B，同時改變了能力組成、訓練資料與模型家族，無法分離。
- 模型 B 若是 API 模型，無法鎖定權重 digest，供應商也可能在背後更新（見 `model-b-candidates.md`）。
- 溫度相同，不代表兩個模型的隨機程度相同；API 模型可能不接受 seed。程式只有在供應商支援時才送 seed，實際是否套用以 audit 的 `seed_applied` 為準。
- 180 案在 RQ1 前導時已看過，RQ2 同樣屬於回溯比較。
- 若裁決者固定為 A，可能偏好 A 的文風；AB／BA 平衡可以讓這個偏差在兩個立場間抵銷，但無法完全消除。建議把模型標籤從裁決者的輸入中移除。

## 呼叫與 GPU 時間預算（估計）

基準：E2′ 實測約 22 案／小時，每案約 2.7 分鐘（22 次決策呼叫＋約 3 次研究呼叫，一張 RTX 5090，US$0.75／小時）。換算約 **7.4 秒／決策呼叫**（研究呼叫成本已攤入）。資料庫的實測值：每次辯論呼叫約 3,700–3,800 輸入 tokens、約 280–310 輸出 tokens。以下假設 gemma3:27b 在實驗室 GPU 上的單次延遲與 A 在 5090 上相近（**未實測**，取決於實驗室硬體）；GPU 依租用時間計費，等待 API 時也在計費。

| 方案 | 每案決策呼叫（A／B／Judge） | 每案時間 | 180 案 | GPU 費用 |
|---|---|---:|---:|---:|
| 只跑異質 4 組（homo 沿用 RQ1） | 28（12／12／4） | 約 3.5 分 | 約 10.4 小時 | 約 US$7.8 |
| ＋homo 重跑（建議） | 42（24／12／6） | 約 5.2 分 | 約 15.5 小時 | 約 US$11.7 |
| ＋homo＋B/B | 56（24／24／8） | 約 6.9 分 | 約 20.7 小時 | 約 US$15.5 |
| 每案只跑一種指派＋homo | 28（18／6／4） | 約 3.5 分 | 約 10.4 小時 | 約 US$7.8 |

- **A、B 在同一張 5090 上輪流載入**：qwen3:32b（約 20 GB）加上任何 24–27B 模型（15–17 GB）都超過 32 GB，無法同時常駐。若按輪次分批排程，每案約需 7 次切換；每次載入約 15–30 秒（**未實測**），每案多約 1.8–3.5 分鐘，180 案多約 5–10.5 小時。
- **（備案）B 用 Gemini 2.5 Flash**：每次呼叫約 US$0.0019（3,800 輸入 × $0.30/M＋300 輸出 × $2.50/M）。異質 4 組每案 12 次 B 呼叫，180 案約 US$4.1；加上 B/B（裁決者仍為 A）約 US$8.2；重試另計。免費層有每日請求上限（數字**待核對**），可能要分多天跑。
- 研究代理人每案約 3 次呼叫，已含在 7.4 秒的換算內。
- 以上都是規劃值，執行前要用 3–5 案的 canary 重新量測。
