## 剩餘邊界

49 個案例仍缺新聞情緒資料，因此不能納入正式主實驗，但可在缺域對照設定下個別執行。這不是技術、SEC、總經、FinBERT 或行情缺口。填補這些案例需要 Alpha Vantage 或另一個具授權、含發布時間的新聞來源。

Docker Desktop 服務當下可支援既有容器測試，但 Windows Docker CLI 在一般權限下回報 named-pipe 存取拒絕；這是 Docker Desktop／Windows 權限問題，非研究服務故障。建議交接時以管理員權限修復 Docker Desktop 的 `docker_engine` pipe 權限，再做一次乾淨重啟驗證。
