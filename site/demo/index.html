1選擇案例

同一份資料、四種判斷方式：A 單次判斷、B 獨立投票、C 固定立場辯論、D 立場交換辯論。選一個案例，看它們各自怎麼判斷。

2流程

從資料快照到 60 日回測，每個案例都走同一條流程。

    3辯論對照

    C 固定立場：代理人甲全程看多、代理人乙全程看空，辯 3 輪後由裁決者定案。D 立場交換：第 2 輪雙方換邊，各自只看得到自己第 1 輪的論點並反駁它；第 3 輪換回，再由裁決者定案。點證據標籤可看對應數據。

    C 固定立場甲永遠看多 · 乙永遠看空
    D 立場交換第 2 輪換邊 · 第 3 輪換回

    4結果

    60 日後實際

    真實模型輸出（RQ1 正式實驗），案例為事後挑選、僅供描述；整體結果：180 案中沒有找到 D 優於 C 的證據，詳見書面報告。不構成投資建議。
