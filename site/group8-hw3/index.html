Hello everyone. We are Group 8. I will present Question 3: hierarchical clustering on the gender_outlier data. In short, the best score came from one extreme person, not from real groups.

STEP 2 / 5◷ 0:40

Data and Methods

SLIDE / REPORT CUEReport page 1: section 3.1

The data has 146 people and three body measurements: height, weight, and waist. We kept everyone. We did not use Gender to make the clusters. We only used it later to describe them.

First, we standardized the three measurements. Weight has a much bigger spread, so without this step, weight would control the distance.

We tried four ways to join clusters. Single linkage uses the closest two points. Complete linkage uses the farthest two points. Group average uses the average of all pairs. Ward joins the two clusters that keep the groups as tight as possible.

STEP 3 / 5◷ 0:45

Choosing the Number of Clusters

SLIDE / REPORT CUEReport page 4: Figure 1, the DB index chart

To choose the number of clusters, from two to eight, we used the Davies-Bouldin index, or DB. It compares how spread out each cluster is with how far apart the clusters are. Lower is better.

Each method picks the k with its lowest DB. Single linkage picks three clusters, with a DB of 0.279. Complete picks four, with 0.616. Group average picks two, with 0.269. Ward picks eight, with 0.750. Group average with two clusters is the lowest overall.

STEP 4 / 5◷ 1:00

What the Clusters Mean

SLIDE / REPORT CUEReport page 4: Figure 2. Then pages 2–3: the table in section 3.3

But look at this winner. One cluster has 145 people. The other cluster has only one person: a man with height 200, weight 130, and waist 40. So this split tells us nothing about gender.

Single and complete linkage also split off one or two extreme people. Ward gives more useful groups. For example, one Ward cluster has 56 people: 52 women and 4 men. On average, they are about 161 centimeters tall and weigh about 49 kilograms.

STEP 5 / 5◷ 0:40

Robustness and Conclusion

SLIDE / REPORT CUEReport page 3: section 3.4. Then page 2: the supplementary table without singletons

Ward's choice of eight clusters is not stable. Eight is the largest k we tried. With a different way to measure spread, Ward picks two instead.

To conclude: by DB, the answer is group average with two clusters. But a one-person cluster has no spread, so it can make the score look good. So we should always check the cluster sizes and centers too. If every cluster must have at least two people, Ward with two clusters gives the best split: 57 people who are almost all women, and 89 people who are almost all men. Thank you.

Thank you. Now I will present Question 5. We used last month's indicators to forecast Container, and compared two models: multiple linear regression, or MLR, and MARS. In short, MARS predicted the test years better, but simply repeating last month's value was even better.

STEP 2 / 6◷ 0:35

Data and Split

SLIDE / REPORT CUEReport page 5: section 5.1

The data has 180 months. To forecast a month, we use each indicator's value from the month before, because that is what we would know in advance. The season index is a calendar factor, so it uses the same month.

The first month has no earlier data, so training uses February 2011 to 2020, which is 119 months, and testing uses 2021 to 2025, which is 60 months. HSI is missing for all 48 months from 2022 to 2025, so we removed it. That leaves 16 possible predictors.

STEP 3 / 6◷ 0:45

Identifying the KPIs

SLIDE / REPORT CUEReport pages 5–6: the KPI table in section 5.2

We used only the training data to find the KPIs. MLR found nine important variables, and MARS chose seven. All seven MARS variables were also chosen by MLR: GCTI, SCFI, the EU and US retail indices, plastic exports, machine imports, and the season index.

So the union is the same nine variables, and we used them in both final models. We tuned MARS with yearly checks inside the training period, and it chose degree 2 and penalty 3.

STEP 4 / 6◷ 1:00

Performance and Plot

SLIDE / REPORT CUEReport page 6: the performance table in section 5.3. Then page 7: Figure 3

On the training data, MARS was better, with a MAPE of 4.3 percent against 5.3 for MLR. On the test data, MARS was also better on all three measures. Its MAPE was 11.0 percent, against 12.5 for MLR, and its RMSE was about 279 million, against 470 million.

But a very simple forecast, just repeating last month's value, had a MAPE of 8.6 percent. That is better than both models.

In the plot, the red line shows where the test period starts. During the big jump in 2021 and 2022, MARS followed the real values closely, but MLR predicted only about 80 percent of them. Later, MARS dropped too early at the end of 2022.

STEP 5 / 6◷ 0:40

Managerial Insights

SLIDE / REPORT CUEReport page 6: section 5.4

What does this mean for managers? The report has four points. Here I group them into three.

First, watch last month's SCFI and GCTI, because both methods chose them as early signals. MARS shows a much stronger push when SCFI is above about 1,200. This is useful for planning, but it is not a strict rule.

Second, look at the EU and US retail indices together, as one signal of consumer demand, because they move closely together.

Third, use the models together with last month's value, and keep extra capacity for sudden peaks, because no single forecast is reliable at the peak.

STEP 6 / 6◷ 0:20

Limits and Conclusion

SLIDE / REPORT CUEReport page 6: the limits paragraph at the end of section 5.4

One limit: we only tested a one-month lag, and some data may be released later than that. To conclude, MARS had the lower test error of the two models, but last month's value was even better. So the models should support that simple forecast, and be checked again when new data comes in. Thank you.

13 prepared questions

Tap a question to reveal the prepared English answer.

01Why did you exclude Gender?Q3
We use Gender to describe the clusters. If we also used it to build them, the comparison would be circular.
02Why standardize? The question did not ask for it.Q3
It is our choice, because weight has a much bigger spread and would control the distance. It does change the result: with raw units, the chosen k changes for three of the four methods.
03Why does DB favor a one-person cluster?Q3
One point has zero spread. If it is also far from the other cluster, the DB score becomes small and looks good, even though the groups are not useful. That is why we also checked splits with no one-person clusters: Ward with two clusters separates 57 people, 53 of them women, from 89 people, 86 of them men.
04Which DB formula did you use?Q3
We measured spread as the root mean square distance to the cluster center. This is the q equals 2 setting in clusterSim. With q equals 1, only Ward changes, from eight clusters to two.
05Why ward.D2 rather than ward.D?Q3
ward.D2 uses Ward's method correctly with normal Euclidean distances, because it squares the distances inside the function.
06Do these clusters predict gender?Q3
No. This is unsupervised clustering. The tables only describe gender in each cluster. We did not build or test a classifier.
07Why use last month's indicators?Q5
To forecast a month, we can only use what is known before it starts. This month's indicators are not published yet, so we use last month's values.
08Why is the season index not lagged?Q5
It is a calendar factor for each month, so next month's value is known in advance. Using last month's factor would match the wrong season.
09Why not impute HSI?Q5
HSI is missing for 48 of the 60 test months. If we filled it in, 80 percent of the test period would get the same made-up value, which adds no real information. If we deleted those rows instead, only the 12 months of 2021 would be left for testing.
10Why did MARS win this time?Q5
In 2021 and 2022, freight rates rose to new highs. MARS can bend at thresholds, such as SCFI near 1,200, so it followed the surge. MLR uses straight lines and fell short. This explains the pattern, but our results do not prove the reason.
11Why do the models lose to last month's value?Q5
Container changes slowly from month to month, so last month's value is a strong guess. The indicators help mainly at turning points: in 2021, MARS beat the simple forecast, 5.2 percent against 6.6 percent.
12Could the season index leak future information?Q5
Maybe, but we cannot prove it. It repeats the same values every year, and the file does not say how it was made. It may have been built from the full Container series. A real model should rebuild it from training data only.
13What are the units of Container?Q5
The file does not say, so we report the original values and do not guess the unit. MAPE has no unit, so it is the easiest measure to compare.
